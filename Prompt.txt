# HSC CHEMISTRY LEARNING PLATFORM
## AI AGENT DEVELOPMENT PLAYBOOK

PROJECT STACK:
React JSX, Vite, Tailwind CSS, React Router, Firebase Authentication, Cloud Firestore, Firebase Storage, Firebase Cloud Functions, ImgBB, Vitest, Playwright.

PROJECT RULES:
- Work in the existing repository.
- Read AGENTS.md and README.md before each task.
- Never overwrite working code without inspection.
- Implement only the requested milestone.
- Never fake successful functionality.
- Run relevant tests and report actual results.
- Never expose API keys or service-account credentials.
- Never deploy without explicit approval.
- Stop and report blockers instead of hiding them.
- Preserve existing working features.
- Update documentation when architecture changes.

==================================================

- Authenticate the requester.
- Verify lecturer/admin authorization.

- Validate image MIME type, size and request payload.
- Apply abuse controls and upload limits.
- Upload the image to ImgBB.
- Validate the upstream response.
- Return the HTTPS image URL and available metadata.
- Handle timeouts, errors and retry safely.
- Preserve the question draft on failure.

Support question, option, explanation, stimulus and subquestion images.

Never put the ImgBB API key in frontend code.

Document the limitations of externally hosted images and backup considerations.

Test unauthorized uploads and simulated API failures.
